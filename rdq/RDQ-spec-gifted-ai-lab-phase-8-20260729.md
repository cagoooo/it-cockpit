# RDQ 需求規格：資優班駕駛艙第八階段

## 一句話任務

從真實 iPad 上課穩定、全年作品與跨裝置紀錄、圖像互動深化、跨域成果展示中，選定下一批 1 至 3 個可驗收功能。

## 四象限盤點

### 已知的已知

- C-01～C-43 已完成，十週課程、NotebookLM、影片、圖片、評量、報告、離線與版本中心皆可使用。
- P0 已完成 4／7；待選為 P0-02、P0-03、P0-07。
- P1 已完成 10／18；待選為 P1-06～P1-10、P1-16～P1-18。
- 對象是一位三年級升四年級資優生，課程以 iPad、教室電腦與實作活動為主。
- 公開網站不得保存姓名、臉部、錄音原檔、答案原文或未核准作品。
- 本次圖片裁切的成功修復已形成 `responsive-image-card-crop-debug` 三平台技能。

### 已知的未知

- 正式上課主要使用哪一台 iPad、iPadOS 版本、可用儲存空間與校內 Wi-Fi 穩定度。
- 教師雲端同步要沿用現有 Firebase 專案，還是採 Google Drive／表單流程。
- 學生作品的保存期限、可接受格式、單檔大小與學年結束後刪除方式。
- 近期是否有家長日、校內成果展或公開展示期限。
- 圖像互動第一版要先做單週示範，還是一次完成十週。

### 未明說但已掌握

- 使用者重視 iPad 實際可見結果，部署成功或檔案存在不能代替視覺驗證。
- 圖片含繁體中文與課程線索，必須完整顯示，不適合以 `cover` 任意裁切。
- 小修正應直接提交推送；跨資料庫、登入、未成年作品與公開展示仍要先確認資料政策。
- NotebookLM 與 Image 2.0 適合產出教材，但網站需保留靜態備援與版本追蹤。

### 尚未出現的未知

- 校內網路限制、內容過濾或第三方平台登入政策可能在正式上課時改變。
- 真實學生可能使用與預期不同的操作路徑，造成新型態的停頓、誤觸或文字理解問題。
- 圖片、錄音、Scratch 檔與影片累積後，儲存空間與同步成本可能高於估計。
- 公開展示可能涉及作品授權、AI 生成揭露或家長同意等額外要求。

## 可選批次

### J：iPad 正式上課穩定 2.0（建議優先）

- 項目：P0-07＋P1-09。
- 交付：課前 60 秒檢查、版本與快取狀態、安全更新、加入主畫面、上課鎖定、離線與外部服務燈號。
- 驗收：真實 iPad 與校內 Wi-Fi 完成一次正常與一次離線演練；更新不遺失教師紀錄。
- 風險：iPad 全螢幕、儲存空間與 PWA 更新受系統限制。
- 量級：中。

### K：全年作品與跨裝置紀錄

- 項目：P0-02＋P0-03＋P1-06。
- 交付：教師登入、跨裝置備忘、私人作品上傳、版本命名、缺件提示與年度專題看板。
- 驗收：iPad 上傳後另一台裝置可看見；未授權訪客不能讀取；可匯出、封存與刪除。
- 風險：未成年作品、Firebase／Drive 權限、費用、備份與資料保存政策。
- 量級：大，應先完成資料治理規格再動工。

### L：圖像互動深化

- 項目：P1-16＋P1-17＋P1-18。
- L1：先選一週建立圖片熱點、找線索、難詞語音與教師觀察，驗證後再擴充十週。
- L2：統一駕駛艙、簡報、影片封面、任務單與報告的視覺規格，建立 AI 圖片重生與版本比較。
- 驗收：單週示範在 iPad、鍵盤、大字與列印模式可用；圖片中文與概念由教師核准。
- 風險：十週一次完成工作量大；圖像互動不能取代動手實作。
- 量級：L1 中，L2 中至大。

### M：成果展與跨域接收

- 項目：P1-07＋P1-08。
- 交付：藝術與科展成果接收模板、匿名學生展示頁、教師核准、QR Code、全螢幕與自動播放。
- 驗收：只顯示核准示範資料；教師備忘與私人檔案不進入公開頁面。
- 風險：需要真實或示範作品；公開前需查核個資、授權與 AI 揭露。
- 量級：中。

### H：非個資改善分析

- 項目：P1-10。
- 交付：週次層級載入成功率、功能使用量與中斷點，不收姓名、答案或作品原文。
- 驗收：統計無法回推單一學生，且提供停用與資料刪除方式。
- 風險：目前只有一位學生，事件數少，統計容易被過度解讀。
- 量級：中；建議正式上課後再啟用。

## 建議順序

1. **J**：先確保真正上課時 iPad、快取、離線與版本穩定。
2. **L1**：選一週把圖片轉成互動探究，先驗證學習價值。
3. **K**：確定 Firebase／Drive、權限與保存政策後，再做全年作品紀錄。
4. **M**：有成果展時提前一個月啟動。
5. **H**：累積真實課堂後再建立非個資分析。

## 共通驗收條件

- [ ] 黃凱揚老師明確選定一組或最多三個項目。
- [ ] iPad 820px、手機 390px、桌機 1440px 無頁面溢位與內容遮擋。
- [ ] 公開頁面不含學生可識別資料，私人資料可匯出與刪除。
- [ ] 核心教學流程保留離線或靜態備援。
- [ ] 每項完成後更新 ROADMAP、版本中心、健康檢查與 GitHub Pages。

## 本次不納入

- 未選定 K 前，不建立學生帳號、Firebase 資料表、Storage 或公開作品入口。
- 未選定 H 前，不加入行為追蹤碼。
- 未選定 L 前，不批次重生十週圖片或大改全部簡報。
- 未選定 M 前，不公開任何真實學生作品。

## 確認方式

回覆 `J`、`K`、`L1`、`L2`、`M` 或 `H`；也可選擇如 `J → L1` 的順序。確認後將本規格狀態改為 `confirmed` 並開始實作。
