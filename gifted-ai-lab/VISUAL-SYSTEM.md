# 石門智繪客全教材視覺設計系統

## 核心原則

1. 先圖後文，一次只呈現一個主要任務。
2. 所有學生文字以三年級升四年級可理解的短句撰寫。
3. 互動控制至少 42px，鍵盤焦點使用黃色 3px 外框。
4. 圖片中的繁體中文、人物與關鍵線索不得裁切。
5. 教師工具使用深綠色；學生行動使用珊瑚紅；提醒使用黃色；連結與資料使用藍色。

## 設計 Token

| 用途 | Token | 色碼 |
|---|---|---|
| 主文字與教師操作 | `--gifted-ink` | `#15383c` |
| 頁面底色 | `--gifted-paper` | `#f6f2e8` |
| 內容底色 | `--gifted-surface` | `#fffdf8` |
| 學生行動與重點 | `--gifted-coral` | `#de5c46` |
| 成功與學習路徑 | `--gifted-teal` | `#168277` |
| 提醒與鍵盤焦點 | `--gifted-yellow` | `#f1bd45` |
| 連結與資料 | `--gifted-blue` | `#3575a7` |

## 圖片規格

- 週次繪本圖：`3:2`、1152×768，使用 `object-fit: contain` 完整顯示。
- 影片與簡報封面：`16:9`，主標題保留安全邊界，不貼近畫面四周。
- 社群分享圖：`1200×630`，主標題、系列名稱與學校資訊保持可讀。
- 所有圖片提供描述內容與教學用途的繁體中文替代文字。

## 元件規格

- 狀態燈：綠色代表可用，黃色代表可上課但要注意，紅色代表上課前需處理。
- 圖片熱點：44px 圓形按鈕，已找到改為綠色，選取時改為深綠色。
- 卡片：圓角不超過 7px，不使用卡片包卡片。
- 按鈕：主要動作深綠底白字；一般動作白底深綠框；同區最多一個主要動作。
- 表單：欄位標籤不可只放在 placeholder；教師備忘明示隱私與保存位置。

## 教材套用範圍

- 年度首頁與十週專用駕駛艙。
- 十週互動投影簡報、上課包與學生任務單。
- iPad 課前檢查、版本中心、報告中心與教師同步視窗。
- NotebookLM 再產出簡報、資訊圖與影片封面時，依本文件使用相同色彩、比例與文字層級。

## 響應式與列印驗收

- 桌機 1440px、iPad 820px、手機 390px 不得水平溢位。
- 文字不遮住圖片線索，圖片不因固定高度放大裁切。
- A4 直式列印不切斷單一活動、量規列或課前檢查項目。
- `prefers-reduced-motion` 開啟時，不依賴動畫才能理解狀態。
